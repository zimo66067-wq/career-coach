## 命名规范

- 版本号：`vX.Y`，X 为主版本（冻结递增），Y 为修订（小改递增）。
- 文件名格式：`<类型>-v<版本>.<扩展名>`，如 `submission-v1.0.pdf`。
- 截图命名：`<阶段>-<功能>-<序号>.png`，如 `g9-f1-001.png`。

## 铁律

1. 不保存真实简历、JD、音频或完整面试记录；只有去标识化合成样本可入库。
2. 所有交付物冻结后不得修改，修改必须走变更流程（新版本号 + CHANGELOG）。
3. 冻结清单是提交的唯一依据，未列入冻结清单的文件不计入交付。
