## 场景 1：正常 ASR + TTS 流程

**测试步骤：**

1. 打开 `ui/prototype/index.html`
2. 进入面试模拟页面
3. 点击"语音回答"按钮
4. 允许麦克风权限
5. 对麦克风说："我在实习中负责后端 API 开发，使用 Go 语言和 MySQL，优化了查询性能，响应时间从 800ms 降到 220ms"
6. 等待 ASR 转写结果显示
7. 确认 TTS 播放下一题

**预期结果：**

- [ ] 麦克风权限弹窗出现并允许
- [ ] ASR 转写结果在 5 秒内显示
- [ ] 转写文本与口述内容语义一致（允许个别字误差）
- [ ] ASR 置信度 >= 0.75（如有显示）
- [ ] 无需手动确认，直接进入下一题
- [ ] TTS 朗读下一题面试问题
- [ ] 整个流程在 10 秒内完成（未触发超时回退）
