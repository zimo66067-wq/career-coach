## 3. 降级方案说明

### 3.1 移动端降级策略

| 场景 | 主路径 | 降级路径 | 触发条件 |
|---|---|---|---|
| 雷达图渲染 | ECharts CDN | 本地 vendor → 六维表格 | 移动端性能不足或 ECharts 加载失败 |
| 语音输入 | 百度 ASR | 文字输入 | 移动端无麦克风权限或 ASR 不可用 |
| 文件上传 | 系统文件选择器 | 粘贴纯文本 | 移动端文件选择器不可用 |
| 网络弱 | 正常加载 | 降级横幅 + 核心功能 | 网络延迟 >5 秒 |
| 屏幕过小 | 完整布局 | 单栏堆叠 + 折叠面板 | 宽度 <375px |

### 3.2 无障碍降级策略

| 场景 | 主路径 | 降级路径 | 说明 |
|---|---|---|---|
| 屏幕阅读器 | ARIA 标签 + 语义化 HTML | 文字表格输出 | 雷达图降级为六维表格后可被读屏 |
| 高对比度 | 标准 CSS | 系统高对比度模式 | 测试系统高对比度下是否可用 |
| 键盘操作 | Tab/Enter/Space | 无 | 所有功能必须键盘可操作 |
| 字体放大 | 响应式布局 | 允许缩放至 200% | 布局自适应，不固定 px 字体 |

### 3.3 降级验证标准

- 每种降级路径必须在 10 秒内切换。
- 降级后核心功能（F1-F4 主路径）仍可完成。
- 降级横幅正确展示，用户知晓当前状态。
- 降级不回退用户已确认的数据。
