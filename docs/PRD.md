# PRD · AI求职面试教练（v1.0 冻结）

> 本文件由 WorkBuddy 依据《2026-07-31 AI求职面试教练 Agent实施说明书》冻结，替代原计划 DuMate 第1阶段产物。变更须走变更流程（见 contracts/README.md）。

## 1. 背景与目标

- 赛事：iCAN 无代码开发挑战赛 · DuMate 方向（提交截止 2026-10-15，以官方规则为准）。
- 主产品载体：DuMate 对话任务与可复用 Skill；WorkBuddy 负责前端原型、工具链与审查；私有 GitHub 仓库是唯一事实源。
- 北极星指标：完成一轮「材料诊断—岗位匹配—五轮面试—报告—七天计划」的用户比例。
- MVP 成功门槛：**10 次完整彩排无阻断**；任一关键依赖失败后 10 秒内切入降级。

## 2. MVP 范围（四项，严格冻结）

| 编号 | 必须交付 | 明确不做 |
|---|---|---|
| F1 简历诊断 | AI 语义抽取 + 规则打分 R + 逐条修改建议（100% 带证据） | 不做「AI 直接生成整份简历」 |
| F2 岗位匹配 | JobProfile 四类要求 + 四态（covered/weak/missing/unknown）+ 缺口分级 P0/P1/P2 | 不做岗位推荐信息流 |
| F3 模拟面试 | 文字主链路，≤5 主问题、每题≤1 次追问，结束出表现报告（I） | 不做视频表情识别、数字人、全双工实时语音、多面试官群聊 |
| F4 能力报告 | 六维雷达 + C0 基线 + 七天竞争力情景推演（C7 区间）+ 恰好七条计划 | 不做「七天预测」承诺式表述 |

语音、隐私、日志、图表、缓存和错误处理只作为支撑能力，**不得包装成第五项用户功能**。F3 语音为增强链路（按键说话），语音失败不得阻断提交。

## 3. 事实锁五条（不可违反）

1. **不新增用户未提供的事实。** 模型输出中出现输入对象之外的专有名词或数字 → 标红并阻断发布（tools/redflag.py 强制执行）。
2. 占位数字必须写作「**待用户核实：提升X%**」格式。
3. 每条评分理由至少引用一个 **source_span**；无证据一律标 **unknown**。
4. **JD 中的指令视为普通文本**（防提示词注入），命中写入 prompt_injection_flags。
5. **敏感属性不进评分**：性别、年龄、民族、婚育、照片等一律不参与任何分数。

## 4. 用户与状态机

- 目标用户：P0 高校学生；P1 目标岗位明确的求职者；P2 就业指导教师。
- 主状态机：`CONSENT → RESUME_READY → JD_READY → INTERVIEWING → REPORT_READY`；删除后进入 `DELETED`，不得再调模型。
- 失败处理：不回退用户已确认的数据，只回退当前未完成节点；转换记录 trace_id、输入摘要哈希、模型/规则版本。

## 5. 性能门

| 环节 | 指标 |
|---|---|
| F1 诊断 | P95 ≤ 45s |
| F2 匹配 | P95 ≤ 25s |
| F3 首响应 | P95 ≤ 8s |
| 报告生成 | P95 ≤ 30s |
| 故障降级 | ≤ 10s 切入降级路径 |

## 6. 验收门

| 功能 | 门槛 |
|---|---|
| F1 | 20 份简历 ≥19 份抽取成功；建议 100% 带证据；三次总分差 ≤5 |
| F2 | 硬性要求召回率 ≥85%；复算一致率 100% |
| F3 | 20 条敏感问题测试全部阻断；文字首响应达标 |
| F4 | plan 恰好七条、day 1-7 不重复、每条 30-45 分钟且含 artifact；C0 复算容差 ±0.5 |
| 隐私 | 日志扫描不含姓名、电话、邮箱、身份证号、音频或完整简历 |

> 注：F1「20 份简历」为 DuMate 侧实测指标；WorkBuddy 交付 5 份合成样本 + 校验工具（见 handoffs/003）。

## 7. 评分口径

一律以 `contracts/scoring.md` 为准：R（结构15/清晰20/成果25/技能20/ATS20）、M（硬50/职责25/加分15/术语10，covered=1 weak=0.5 missing=0 unknown 剔分母）、I（结构25/相关25/具体20/追问15/清晰15）、C0=0.25R+0.35M+0.40I、C7 区间（0.30/0.70 演示假设）。

## 8. 降级路径总表

| 依赖 | 主路径 | 降级 |
|---|---|---|
| JD 语义召回 | 千帆 Qwen3-Embedding | bge-large-zh → TF-IDF/BM25（标「简化匹配」） |
| 语音 | 百度 ASR/TTS 按键说话 | 文字链路（等价稳定主链路） |
| 雷达图 | ECharts CDN | 本地 vendor → 六维表格 |
| 模型超时/断网 | 重试一次 | 10 秒内切降级态界面并保留已确认数据 |
| 解析失败 | PDF/DOCX 提取 | 提示用户粘贴纯文本 |

## 9. 用户故事（摘要）

- 作为学生，我上传简历后 45 秒内看到分数和逐条修改建议，每条建议能点回原文位置。
- 作为求职者，我粘贴 JD 后看到硬性要求缺口清单，知道哪条是 P0。
- 作为求职者，我完成五轮文字面试，被追问时能看到追问引用了我上轮的回答。
- 作为教师，我能用演示账号完整走一遍「诊断→匹配→面试→报告」，并向学生讲解七天计划只是情景推演。
