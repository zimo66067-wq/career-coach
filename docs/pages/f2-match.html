术语说明

什么是 JD？

JD 是 Job Description 的缩写，指招聘方发布的职位描述 / 岗位要求。

  • 岗位职责：入职后需要完成的工作
  • 任职要求：学历、经验、技能等条件
  • 加分项：优先但非必须的能力或经历

可上传格式
PDF、DOCX、TXT；单个文件不超过 10MB。
