## 三、技术路线

### 3.1 数据层
- 目录：教育部官网《普通高等学校本科专业目录（2025年）》附件2 PDF，`scripts/build_majors_data.py` 程序化解析（6-7 位代码兼容，含 T/K 标记与备注）。
- 画像：`profiles_top30.json`，每个专业含 `direct`（强/较强对口）与 `derivative`（较弱/弱衍生）两组方向；方向含职业、常见岗位、技能、匹配关键词。
- 数据血缘：`majors_2025.json` 带 `version` + `source`；画像带 `source`（人社部《职业信息与教育培训项目（专业）信息对应指引（2023年版）》+ AI 批量生成）。
- 存储：静态 JSON（只读数据），后续可平滑迁移 SQLite/Postgres，接口契约不变。

### 3.2 服务层（`api/f2_major.py`，Flask）
- `GET /api/f2/majors/tree`：完整目录树（门类 → 专业类 → 专业）。
- `GET /api/f2/majors/search?q=`：名称/代码/专业类模糊搜索，前 20 条。
- `GET /api/f2/majors/<code>`：专业详情 + 画像（无画像返回 `profile_status=building`）。
- `POST /api/f2/match`：`{majorCode, resumeText, jdText?}` → 双模式结果。
- `GET /api/f2/intent?q=`：按求职意向反查专业（如"程序员"→计算机/软件）。
- 本地同时托管 `ui/prototype` 静态页；Vercel 侧通过 `?_route=` 复用同一路由函数。

### 3.3 匹配引擎（规则 + BM25 混合）
- 分词：ASCII 词 + 中文二元组，支持中英混合简历。
- 模式 A（无 JD）：简历 vs 每个方向的画像关键词 → 命中率 = 岗位覆盖分；方向按分数排序，输出命中/缺口关键词。
- 模式 B（有 JD）：JD 拆条 → 硬性/职责/加分/术语四类 → 四态（covered/weak/missing/unknown）+ 加权岗位覆盖分；JD 与专业画像做职业识别 → 专业契合分（强=100/较强=82/较弱=58/弱=40）。
- 双分制：`专业契合分` + `岗位覆盖分`；综合 M = 0.4×契合 + 0.6×覆盖（契合不可得时以覆盖为准并注明）。
- 缺口分级：P0 硬性未命中 / P1 职责未命中 / P2 其余，附改写建议。

### 3.4 前端层（零构建、零依赖）
- 四步向导 + 步骤指示器；专业量大场景的可用性设计：
  1. 三级联动（门类 12 → 专业类 93 → 专业 845）；
  2. 全局搜索（名称/代码，防抖 220ms，下拉即时结果）；
  3. 常用专业快捷芯片（12 个高热度专业）；
  4. 最近选择（localStorage 记忆 6 个）；
  5. "不确定专业"入口：按求职意向反查推荐专业。
- 报告页双环图（专业契合/岗位覆盖）+ 综合 M 大数；模式 A 方向卡片、模式 B 四态清单与证据关键词、缺口行动建议。
- 历史联动：匹配完成自动写入侧边栏历史（`ZY_ACCOUNT.addHistory`）。

## 四、全链路用户流程

```
选择专业（联动/搜索/常用/最近/意向反查）
  → 查看岗位画像（对口 + 衍生方向）
  → 上传/粘贴简历（可选粘贴 JD）
  → 开始匹配（无 JD=模式A；有 JD=模式B）
  → 双分制报告（专业契合 + 岗位覆盖 + 综合M）
  → 自动写入历史记录
```

## 五、里程碑依赖关系

```
R0 数据底座 ──→ R2 自动校验
R1 画像生成 ──→ R2 自动校验 ──→ R3 匹配引擎 ──→ R4 前端 ──→ R5 端到端
```

- R3 依赖 R0/R1 的数据契约（代码、名称、方向等级）。
- R4 依赖 R3 的响应契约（`modeA`/`modeB`/`scores` 嵌套结构）。
- R5 依赖本地服务与静态托管合一（8123 单端口）。

## 六、技术选型

| 关注点 | 选型 | 理由 |
|---|---|---|
| 后端 | Flask 单文件 + JSON 只读数据 | 与现有 `api/index.py` 同栈、Vercel 兼容、零新依赖 |
| 前端 | 原生 HTML/CSS/JS（零构建） | 延续原型规范，file:// 与本地服务均可打开 |
| 匹配 | 规则 BM25 + 关键词证据 | 无需 LLM Key 即可演示；证据可审计，后续可无缝叠加模型层 |
| 部署 | 本地 8123 + Vercel 备用 | 演示即时可用；Vercel 经 `?_route=` 复用路由 |
| 数据 | JSON + 版本/来源字段 | 可审计、可迁移、低维护 |

### 7.3 匹配用例（计算机科学与技术 080901）
