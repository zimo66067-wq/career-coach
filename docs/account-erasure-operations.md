# 账号数据保留与人工请求：上线门禁

更新：2026-10-02。此文档描述用户已选定的业务规则、当前可用的代码能力及尚未打通的环节；不是“已启用自动删除”的声明。

## 已定规则

- 账号及其关联的去标识化简历文本、岗位、面试和申请数据，在账号持续使用期间保留。
- 连续 12 个月未登录时，须提前通知并留出回访机会，再删除账号关联业务数据。具体提前通知天数待最终确认。
- 核验通过的查阅、复制、更正或删除申请应人工受理，不必等待不活跃期结束。网站公开的受理邮箱为 `zimo66067@gmail.com`；邮件中不得收取密码、身份证照片或简历原文件。
- 用户暂不启用自助账号注销。原文件长期保存及管理员后台属于上线后独立版本。密码仅保存哈希，不能查询原文。

## 本分支已准备的技术能力

- `repositories/account_privacy.py::erase_verified_user` 为**内部函数**，没有 HTTP 路由、管理页面或定时任务入口；必须显式传入已完成人工身份核验的标志，只接受普通用户数字 ID，拒绝管理员账号。
- 在单个数据库事务中清除账号、登录会话、历史、归属会话、去标识化简历及诊断、匹配/面试/能力/改写、求职档案/证据、岗位及其要求/缺口/行动/决策、申请及结果、用量记录；任何一步出错即回滚。若历史记录出现同一工作流会话关联不同账号的冲突，立即中止并回滚，不能冒险删除别人的资料。返回各表删除数量，不返回个人信息。
- 隔离 SQLite 测试覆盖：未核验拒绝、另一用户隔离、各关联表删除、重复调用、事务异常回滚、冲突归属保护和管理员保护。PostgreSQL 上尚未执行删除演练。
- 页面不再笼统承诺“长期保存”；但网站也不会声称 12 个月规则已自动执行。
- 新注册账号以 `created_at` 同时初始化 `last_login_at`，为未来不活跃期计算提供起点；既有 `last_login_at` 为空的账号仍需在启用调度前制定 `created_at` 回退或补核规则，不能直接当作已经满足删除条件。

## 不能越过的生产门禁

1. **身份核验**：注册邮箱和手机号目前未验证。仅凭发件地址或自报账号信息不能视为本人。设计并验证受理人确认、登录态佐证及操作复核流程后，才能人工执行真实账号删除。
2. **备份与恢复**：确认生产 PostgreSQL 提供方、实例和备份保留期；先在隔离库完成恢复演练，记录恢复点、表关系及合成账号读写结果。当前不得用生产库做删除演练。
3. **通知交付**：目前无已验证发信域名、邮件服务或投递监测。收到“提前通知”业务口径后，仍需接通可靠通知、记录发送结果、退信处理与登录取消删除的逻辑；未满足前不得启用 12 个月自动清理。
4. **邮箱验证与存量账号**：建立新注册邮箱验证或等效通知地址确认方式，并制定存量未验证邮箱的补验证路径，避免向错填/冒用邮箱投递账号信息。
5. **数据权利核对**：人工请求需可追踪受理、身份核验、执行、复核及反馈时间。现有 `POST /api/wf06/delete` 仅删除单次会话资料，不等同账号全量删除；备份副本应按已核实的保留周期处理，不能宣称实时擦除。

## 操作约束

内部删除能力在上述门禁未通过前只允许对隔离测试库中的合成账号调用。不得从邮件里的 ID 直接调用、不得对管理员调用、不得为验证此功能而删除生产真实用户。上线前需用独立 PostgreSQL 测试库重复完整事务与跨用户隔离测试，并留存脱敏结果。

## 人工请求核验预案（尚未接通，不构成可执行删除流程）

1. **受理**：只登记请求类别、受理时间和随机工单号。来信中的邮箱、手机号、账号 ID、历史截图或自述经历均不能单独证明账号归属；不索取密码、验证码、身份证照片或简历原件。工单记录不得复制简历正文。
2. **账号内确认**：后续须提供由当前登录会话发起的专用请求入口，并把请求、账号 ID、用途及有效期绑定。当前没有该入口，不能把普通邮件、`/api/auth/me` 截图或客服口头确认当成已完成核验。注册邮箱和手机号仍需各自的验证/纠错机制。
3. **复核**：执行人与复核人分别核对工单、账号类型、请求范围、登录态佐证和关联数据清单；有归属冲突、管理员账号、失效会话或资料不一致时停止，不调用删除函数。记录核验结论和复核人，不记录会话令牌。
4. **执行前门禁**：先确认生产实例身份、备份保留期和隔离恢复演练结果；再于独立 PostgreSQL 测试库用合成账号验证删除、跨用户隔离与回滚。实际用户删除还须另行确认操作范围及恢复限制，且不能以测试库结果冒充生产执行结果。
5. **执行后核对**：仅记录工单号、操作时间、代码/迁移版本、各表删除数量与无关账号未受影响的核对结论。反馈时区分在线主库与备份副本的处理状态，不承诺未经验证的即时全域擦除。

上述第 2 步尚无产品入口，第 4 步尚无独立 PostgreSQL 演练证据；目前公开邮箱可收到请求，但没有经验证的身份核验与执行闭环，不能把此预案标记为已上线的账号删除服务。
