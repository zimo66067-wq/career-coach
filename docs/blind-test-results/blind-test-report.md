## 五、模型能力评估

### 优势

1. **结构化输出稳定**：三轮测试均按Schema输出完整JSON，无格式错误
2. **source_span引用准确**：所有评分理由和修改建议均回指原文片段
3. **量化评分合理**：分数分布与候选人实际质量一致（初级72→中级88→高级85）
4. **追问针对性强**：每个追问均聚焦具体Gap，预期回答要点清晰
5. **事实锁合规**：未发现编造数据或引入简历外信息

### 不足

1. **初级简历评分偏低**：对初级候选人（张伟）的F1评分72分，可能过于严格
2. **追问数量不稳定**：Round 3仅生成2个问题（vs Round 1/2的3个），对高级候选人追问偏少
3. **建议数量固定**：每轮均为3条建议，未根据候选人质量动态调整
4. **缺少多轮对话模拟**：F3仅生成首轮追问，未模拟候选人的回答和后续追问

### 改进建议

1. **校准初级评分标准**：初级候选人应有更宽松的评分基准（如结构完整度+5分）
2. **动态调整追问数量**：根据Gap数量和重要性动态决定追问数（2-4个）
3. **增加建议数量弹性**：高质量简历可减少建议数量，低质量简历增加具体指导
4. **补充多轮对话模拟**：增加候选人的模拟回答和面试官的后续追问
