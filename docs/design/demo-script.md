# demo-script.md · 现场演示脚本（原型走查版，≤8 分钟）

> 用途：G9 前的原型演示与彩排走查（tests/rehearsal/demo-checklist.md 逐条核对）。正式 4分30秒比赛演示以 DuMate 主产品为准，本脚本与其时间轴对齐。

## 分镜

| 时间 | 动作 | 台词要点 |
|---|---|---|
| 0:00-0:30 | 打开 `ui/prototype/index.html` | 「求职者最大的痛苦是不知道简历差在哪、面试输在哪。我们的原则是：模型做语义，规则做分数，验证器做事实。」 |
| 0:30-1:30 | 进 F1 页（success）→ 点击 2 条评分理由，展示原文高亮 | 「每个分数都能点回原文位置。找不到证据的，系统标 unknown，绝不编。」 |
| 1:30-2:30 | 进 F2 页 → 指四态徽章与 P0 缺口 | 「四态互斥：unknown 不进分母——不知道不等于不满足。」 |
| 2:30-4:00 | 进 F3 页 → 指追问引用块 | 「追问不是模板：它引用了上一轮回答的原句，并指出 STAR 缺口。」 |
| 4:00-5:00 | 进 F4 页 → 雷达 + C7 区间 + 七天计划 | 「这是情景推演区间，第七天复测才是真实变化——我们不做预测式承诺。」 |
| 5:00-6:00 | 状态墙 → F2 `?state=degraded` | 「断网或语义服务故障，10 秒内切降级路径，界面明确标注简化匹配。」 |
| 6:00-7:00 | F4 `?state=degraded`（雷达→表格）→ F3 `?state=error` | 「降级不是白屏：图表变表格，数值完全一致；校验不过就阻断，不展示不可信内容。」 |
| 7:00-8:00 | 回到首页收尾 | 「语音是增强层，文字是等价稳定主链路。所有数据已去标识化。」 |

## 现场切换口令（任一依赖失败时）

1. 「语音是增强层，文字是等价稳定主链路。」（语音故障）
2. 「已切换简化匹配，恢复后自动重算。」（语义服务故障）
3. 「图表降级为表格，数值一致。」（CDN/图表故障）
4. 「已确认数据不受影响，只回退当前节点。」（网络/超时）

## 口径红线（不得说）

- 不说「预测」，统一「七天竞争力情景推演」
- 不说「这个分数代表录用概率」，统一「证据覆盖指数」
- 不展示任何真实简历/真实 PII
