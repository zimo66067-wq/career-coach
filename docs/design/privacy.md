# privacy.md · 隐私与数据安全（v1.0 冻结）

## 1. 去标识化字段清单

进入任何模型调用与评分流程前，以下字段必须由 `domain/deidentify.py` 脱除：

| 字段 | 脱除标记 |
|---|---|
| 姓名 | `[REDACTED_NAME]` |
| 手机号 | `[REDACTED_PHONE]` |
| 邮箱 | `[REDACTED_EMAIL]` |
| 身份证号（18 位） | `[REDACTED_ID]` |

脱除完成后文本尾部追加 `pii_removed:true` 标记行；ResumeProfile.pii_removed 必须为 true 才允许进入评分。

## 2. 数据最小化与入库规则

- 仓库只保存：**去标识化合成样本**、配置、提示词、工作流定义、文档、截图。
- 绝不入库：真实简历、真实 JD、音频、完整面试记录、PII 映射表（`--map` 默认不落盘）。
- `.gitignore` 已默认排除 `*.pdf` / `*.docx` / `*.log`（合成样本白名单除外）。

## 3. 敏感属性不进评分

性别、年龄、民族、婚育、照片、籍贯等敏感属性一律不参与 R/M/I/C0 任何计算；模型提示词中已内嵌该禁令（prompts/ 各模块「事实锁」段）。

## 4. 日志脱敏

- 所有工作流日志落盘前必须经 `domain/internal/log_sanitize.py` 管道处理（复用 deidentify 规则 + token/AK-SK 模式）。
- 质量门：日志扫描不含姓名、电话、邮箱、身份证号、音频或完整简历。

## 5. 用户删除流程（WF-06 约定）

2026-09-28 核心版边界：WF-06 删除的是当前工作流会话，不是账号注销。职业档案、已确认/待确认的长期证据、目标岗位、账号及限流元数据仍保留；响应以 `scope=workflow_session` 和 `retained` 明示。单条证据和目标岗位使用对应删除接口。服务端删除失败时，清除浏览器缓存不得宣称服务端已删除。下列停止模型处理约束适用于被删除的会话；完整账号注销与全量清除仍需独立实现与验收。

1. 用户发起删除 → 状态机进入 `DELETED`。
2. 删除生效后**不得再调任何模型**处理该用户数据。
3. 本地缓存、会话变量、日志中的残留同步清除（日志按第 4 节已脱敏）。
4. 删除动作记录 trace_id（不含内容）。

## 6. 未成年人与合规口径

- 本系统不收集敏感属性；如发现材料中含身份证号等，先脱除再处理。
- 对外口径：分数是「证据覆盖指数」，不是录用概率；行动计划不是就业结果预测，C7 情景预测已退役。
