# WF-06 · 异常处理与数据删除（占位，DuMate 实现）

- **输入**：任意工作流异常 / 用户删除请求 / 依赖故障
- **输出**：降级态界面（参照 ui/prototype/pages/states.html）/ DELETED 终态
- **主路径**：捕获异常 → 记录 trace_id + 输入摘要哈希 + 模型/规则版本 → 10 秒内切换降级路径 → 日志经 log_sanitize.py 落盘
- **降级映射**：
  - 模型超时/断网 → 重试一次后切降级态横幅，保留已确认数据
  - 语音故障 → 回退文字主链路
  - 图表故障 → 表格降级
  - 解析失败 → 引导粘贴文本
- **删除流程**：用户删除 → 状态 DELETED → 不再调用任何模型 → 清除会话/缓存残留 → 记录 trace_id（不含内容）
- **退出标准**：故障 10 秒内降级可演示；删除后无任何模型调用；日志扫描无 PII
- **禁止**：失败时回退用户已确认的数据（只回退当前未完成节点）
